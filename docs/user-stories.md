
As a Counter Worker
I want to register a bike when it arrives
so that the workshop can identify it and track its repair.

As a Mechanic
I want to know the bike's current repair status
so that I can inform anyone who calls about the state of a bike.
 
 **Acceptance Criteria**

- The current repair status of the selected bike is displayed.
- The repair status is visible to every Mechanic.
- The screen only shows the repair status of the bike being consulted.


As a Counter Worker
I want to see the current price of each service
so that I can calculate the expected charge for a repair.

As a Mechanic
I want to record the condition of a bike when it arrives
so that I can back up the initial state of the bike.

**Acceptance Criteria**

- The initial condition of the bike is recorded when it is received.
- At least one photo of the bike can be associated with the intake record.
- The recorded condition and photos can later be consulted for that bike.

As a Counter Worker
I want to know the promised date of a repair
so that I can see when a repair is overdue before the Client calls.

As a Counter Worker
I want to see the price charged for each service in a past repair
so that past repair totals remain accurate when the current price list changes.

As a Visitor
I want to see the available services and their prices
so that I can know what the shop charges without calling.

**Acceptance Criteria**

- Every displayed service includes its current price.
- Only public service information is shown.
- No Client or repair information is visible on the public page.
- If no services are available, the page explicitly indicates that there are currently no services to display.

As a Mechanic
I want to record a detailed diagnosis
so that the Client can understand what is wrong with the bike before approving the repair.

**Acceptance Criteria**

- The recorded diagnosis is visible for the selected repair.
- The mechanic can record the identified problems with the bike.
- The diagnosis shown corresponds only to the selected repair.

As a Counter Worker,
I want to be able to charge less than the listed price,
so that I can adjust the price when a job is easier than expected or for a regular Client.
